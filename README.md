# 3D Learning Lab

Teacher-first, offline-first interactive 3D teaching laboratory for Android.

## Development

The repository is being developed in stages:

1. Concept and product planning
2. Android foundation
3. Automated GitHub build validation
4. 3D viewer prototype
5. Educational 3D interactions
6. Content expansion
7. Classroom-ready polish

See `CONCEPT.md`, `PRD.md`, `ARCHITECTURE.md`, `SCHEMA.md`, and `TASKS.md` for the project plan.

## Current status

The Android Compose foundation is in place. GitHub Actions builds a debug APK so development can continue without Android Studio.
